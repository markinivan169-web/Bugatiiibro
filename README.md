# Tourbillon — The art of engineering

Независимое интерактивное исследование Bugatti Tourbillon. Vite, React 19, TypeScript, Three.js, React Three Fiber, drei, GSAP ScrollTrigger, Lenis и Tailwind CSS 4.

## Запуск

Требуется Node.js 22.12+ (или поддерживаемая Vite версия Node 20.19+).

```bash
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite. Production:

```bash
npm run build
npm run preview
```

Для размещения на статическом хостинге загрузите содержимое `dist/`.

## Управление

- Прокрутка управляет одной закреплённой сценой: силуэт → поворот → разборка → обзор → каталог.
- Прокрутка вверх собирает автомобиль обратно. Индикаторы слева позволяют перейти к нужному этапу.
- После 85% выберите деталь в 3D или в каталоге из 12 систем.
- Потяните мышью или пальцем, чтобы повернуть выделенную деталь. Десктопное колесо мыши оставлено прокрутке страницы, чтобы не конфликтовать со ScrollTrigger.
- Back to exploded view / Escape возвращает всю композицию. Reset view также сбрасывает орбитальную камеру.
- На телефонах панель деталей прокручивается отдельно от страницы.
- При `prefers-reduced-motion` показывается статичный рендер, прокрутка без Lenis и полный каталог. Интерактивный 3D можно включить явно.
- При потере WebGL-контекста отображается локальный постер, сохраняются данные каталога и доступна кнопка повторной загрузки сцены.

## Модель и достоверность

В проекте не было исходных 3D-ассетов. Доступного для прямого использования GLB с проверяемой подходящей лицензией не найдено. Поэтому модель полностью процедурная: это стилизованная визуализация, **не фотореалистичная копия, не заводской CAD и не инструкция по ремонту**. Внутренние формы, расположение деталей, колёсные диски и границы панелей схематичны.

`src/utils/vehicle.ts` создаёт 27 независимых групп, 81 геометрический batch и около 65 тысяч вершин. Геометрия одного материала объединяется внутри каждой группы; части сохраняют собственные pivot, исходную позицию и траекторию. При прокрутке объекты обновляются на месте и не пересоздаются.

Характеристики отделены от геометрии в `src/data/components.ts`. Источники:

- [Bugatti: Tourbillon world premiere, June 2024](https://newsroom.bugatti.com/en/press-releases/the-bugatti-tourbillon-an-automotive-icon-pour-leternite)
- [Bugatti: Technical specifications, June 2024](https://bugatti.imgix.net/67c6fea99ff3da200bba241e/technical-specifications-bugatti-TB-en.pdf)
- [Bugatti: The new platform](https://newsroom.bugatti.com/press-releases/a-new-foundation-for-a-new-era)

Данные отражают эти публикации, а не обещание актуальности всех серийных параметров. 252 кг — масса только ДВС; 700 г — только приборного блока. Для неопубликованных данных используется «Не опубликовано». Стоимость отдельных компонентов не оценивается. Это неофициальный проект без связи с Bugatti.

## Ресурсы и производительность

Внешняя 3D-модель, видео, платный API и сетевой HDRI не требуются. Окружение строится из локальных lightformer-источников. Постер — рендер самой процедурной модели. Шрифт Manrope размещён локально, лицензия SIL OFL в `public/fonts/OFL.txt`.

3D-код загружается динамически. DPR ограничен 1.5, на мобильном устройстве — 1. Используется demand-рендеринг, при скрытии вкладки рендер останавливается. Геометрия и материалы освобождаются при размонтировании; Lenis и GSAP очищают свои обработчики. Частота кадров зависит от оборудования; гарантированных 60 FPS нет.

## Структура

```text
src/components/   навигация, hero, сцена, каталог, панели
src/data/         отдельные технические данные и источники
src/hooks/        Lenis / GSAP / управление прогрессом
src/utils/        процедурная модель и траектории
public/fonts/     локальный Manrope и лицензия
public/poster.webp статичный fallback
```

Статическая публикация описана в `.openai/hosting.json`. Для независимого развёртывания этот файл не требуется.
